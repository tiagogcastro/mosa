# Design and integration references

Reviewed the public GitHub repository descriptions, license and maintenance metadata, and available README files for these twenty projects on 30 October 2026. This was **not** an authenticated inspection of commercial streaming applications or a license to copy their code. Public interface references supplied by the owner informed the compact sidebar (Apple TV), content rails (Netflix), live categories (Globoplay), and channel guide affordances (Prime Video).

| Projects                                                                                                                                                                                                                                                                                       | Useful pattern / decision for Mosa                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [IPTVnator](https://github.com/4gray/iptvnator), [Hypnotix](https://github.com/linuxmint/hypnotix)                                                                                                                                                                                             | Separate provider/playlist setup from channel browsing and do not supply streams.                                                                                          |
| [Jellyfin Web](https://github.com/jellyfin/jellyfin-web), [Jellyfin Vue](https://github.com/jellyfin/jellyfin-vue)                                                                                                                                                                             | Media-library navigation and artwork hierarchy; no code imported from GPL projects.                                                                                        |
| [Dispatcharr](https://github.com/Dispatcharr/Dispatcharr), [Threadfin](https://github.com/Threadfin/Threadfin), [Tvheadend](https://github.com/tvheadend/tvheadend)                                                                                                                            | EPG and mapping are separate concerns from playlist import. No proxy/transcoding infrastructure adopted.                                                                   |
| [Kodi IPTV Simple](https://github.com/kodi-pvr/pvr.iptvsimple)                                                                                                                                                                                                                                 | The stream format determines which live controls work; M3U and XMLTV are separate inputs.                                                                                  |
| [Free-TV/IPTV](https://github.com/Free-TV/IPTV), [iptv-org IPTV](https://github.com/iptv-org/iptv), [iptv-org API](https://github.com/iptv-org/api)                                                                                                                                            | Public playlists represent live-channel listings, not a verified film catalog; match extra logos only with reliable identifiers.                                           |
| [Guovin IPTV Player Web](https://github.com/Guovin/iptv-player-web), [Ghosten Player](https://github.com/GhostenEditor/Ghosten-Player), [Streamity](https://github.com/lKinderBueno/Streamity-Xtream-IPTV-Web-player), [Another IPTV Player](https://github.com/bsogulcan/another-iptv-player) | Keep IPTV category/channel/player navigation compact and provider-aware. No provider-specific compatibility is claimed from these examples.                                |
| [Media Chrome](https://github.com/muxinc/media-chrome), [Shaka Player](https://github.com/shaka-project/shaka-player), [hls.js](https://github.com/video-dev/hls.js), [ArtPlayer](https://github.com/zhw2590582/ArtPlayer), [Video.js](https://github.com/videojs/video.js)                    | Media Chrome offers composable controls but currently points new users toward Video.js; retaining Shaka and showing only supported tracks avoids a second playback engine. |

[PWA guidance](https://nextjs.org/docs/app/guides/progressive-web-apps) and the installed Next.js manifest reference were checked before adding install metadata. Installation does not make the local backend or IPTV streams available offline.
