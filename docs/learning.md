# Learning entry points

1. `src/db/schema/index.ts` — provider-aware identities and relational persistence.
2. `src/features/providers/service.ts` — adapters, import transactions, source resolution.
3. `src/features/catalog/queries.ts` — server-side queries for media collections.
4. `src/features/playback/components/player.tsx` — browser-only media lifecycle and progress.
5. `src/lib/security/remote.ts` — bounded network reads and destination validation; review the documented limitations before enabling remote access.
